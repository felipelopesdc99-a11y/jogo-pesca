# Assets/Resources

`BackendSettings.asset` belongs here, but it is **not** committed: the client runs without it,
falling back to `http://localhost:5080`, which is what the local Docker Compose stack serves.

To point the client at a different server, pick whichever is more convenient:

1. **Environment variable** — set `FISHING_IDLE_API_BASE_URL` before launching the editor or the
   built player. This wins over the asset.
2. **Settings asset** — in the editor, `Assets > Create > Fishing Idle > Backend Settings`, save it
   here as `BackendSettings.asset`, and edit the fields in the inspector.

The asset is left uncommitted on purpose: each developer's server URL is a local concern, and the
file's script reference (a GUID) is generated by the editor rather than written by hand.
